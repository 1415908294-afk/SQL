## 架构

```text
React + TypeScript + Tailwind / Vite
  ├─ 首页 / 七阶段课程 / 数据字典 / 本地学习记录
  ├─ Monaco（项目本地资源） → SQL 格式化
  └─ 查询请求 → DuckDB 原生分词器 → SELECT 子查询上下文解析
              → DuckDB-Wasm Worker（READ_ONLY，外部访问关闭）
              → Arrow 数据 → 日期/金额/整数规范化
              → 表格 / CSV / 标准结果比较 → localStorage

Node 开发工具
  ├─ 确定性数据生成 → voca.duckdb
  ├─ 标准 SQL → expected.json
  └─ 原生验证 + 同版本 Wasm 执行验证
```

目录：src/content 课程、练习、预期结果；src/lib 查询引擎、策略、判题、存储；src/App.tsx 页面交互；src/style.css 布局；scripts 资源复制与验证；public 数据库和引擎；docs 文档。后续页面复杂度上升时将 App 拆为独立路由和 components。

## 只读与隔离

1. 写入保护由数据库 READ_ONLY 强制执行，脱离界面策略直接执行写操作仍会失败。
2. 每次重载读取原始数据库文件，进度存于单独 localStorage，不向数据库写数据。
3. 初始化后关闭 enable_external_access、自动安装和自动加载扩展，lock_configuration 锁定设置。
4. 使用 DuckDB tokenizer 的 UTF-8 字节偏移识别语句终结分号，不把字符串分号当作多语句。不使用危险词黑名单。
5. 提交内容放入 SELECT 的子查询关系上下文，再 prepare 执行，由数据库解析器检查合法性；允许安全 WITH、窗口、子查询。仅允许一条查询。
6. 15秒超时终止 Worker，限制返回1001行，用第1001行识别截断。限制返回行数不能替代查询计算资源限制；极重查询仍可能在超时前占用较多内存，未来可加入独立请求 Worker 生命周期与内存预算。
7. CSV 导出转义逗号与双引号，并中和可能触发表格公式的开头字符。

前端数据库用于学习，不是对恶意网站脚本的安全沙箱；用户在开发者工具可查看所有模拟数据与标准答案。无私密数据，服务端 API 密钥必须另行管理。

## 指标口径

- 用户：users 每行一个 user_id，注册表也是一人一次；不能把对话或活跃事件行数当成人数。
- 新增：按 signup_date 统计用户。日期为合成自然日，无时区转换。
- DAU：当日 activity_events 的去重 user_id。未来 WAU/MAU 必须明确自然周/月还是滚动7/30天。
- 激活：注册当日完成至少一段 AI 对话；激活率分母为该注册群体人数。
- 次日留存：注册日+1恰好当天有活跃事件；按注册 cohort 去重。7日留存必须排除未达到完整观察期的 cohort。
- 漏斗：注册 → 首次对话 → 在首次对话当日或之后有效支付；是按用户的封闭漏斗，不是三个独立计数。
- 收入：仅 status='paid'，人民币；不计 refunded；非财务净收入。
- 付费率：有效付费去重用户/全量用户。ARPU：有效收入/全量用户；ARPPU 则按付费用户做分母，不可混用。
- 当前数据存在人为生成相关性，只用于校验 SQL，不支持真实业务因果结论。

## 三阶段计划与验收

### 第一阶段：可学习、可真实执行

课程、六表数据、至少10题、Monaco、只读执行、格式化、中文报错、导出。验收：标准答案跨原生与 Wasm 结果一致，SELECT/WITH 正常，写入直接被数据库拒绝，外部访问不可用，构建通过；浏览器交互需另行通过后，才进入下一阶段。

### 第二阶段：业务题与分析反馈

扩展到至少50题，每题业务背景、口径、分级提示、SQL和固定预期结果齐备。增加空 cohort、跨月、重复事件、一对多订单、退款和零分母等数据边界；结果比较加强非有限数与精确数值处理。完善进度、每日学习、复习推荐和 Recharts 图表。

验收：所有标准 SQL 自动通过，故意错误 SQL 被拒绝；DAU/WAU/MAU、次日/7日留存、激活、漏斗、渠道质量、付费率/ARPU和功能使用覆盖完整；存储恢复与数据可视化浏览器测试通过。

### 第三阶段：导师、作品集、发布

安全代理接口建议 `POST /api/tutor`：mode 取 error/hint/explain/review；lessonId、exerciseId、SQL与错误为输入，allowFullAnswer 默认 false。密钥仅后端环境 `DEEPSEEK_API_KEY`；服务端请求体校验、限流、超时、来源控制、日志脱敏。默认只给分步提示；明确请求完整答案时才展示。完整答案内容由后端按 exerciseId 控制，不把系统提示当保密边界。

产出完整运营分析项目，包含业务问题、指标口径、SQL、图表、结论、局限与下一步实验，支持报告导出；明确标注模拟数据。随后根据用户指定的 GitHub 仓库发布源码，在指定部署账户上线。

验收：前端与构建不含密钥，未授权请求/限流/上游错误处理通过，默认提示不泄露完整答案，作品集报告可导出，线上 Wasm/Worker/SQL/存储通过回归。
